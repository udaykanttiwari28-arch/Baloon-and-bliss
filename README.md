# Balloons & Bliss website

The live site is deployed by Vercel from this repository.

## Write a blog post

Posts are written in Markdown under `posts/`. Copy an existing `.md` file, then update its front matter and content.

Upload a new image to the repository first, or use its Cloudinary URL in the post's `<img src="...">`.

The current site is plain HTML, so Markdown is the editable source and `blog.html` is the visitor-facing rendered page. Update both before committing; a future CMS or static-site migration can automate that step if publishing volume justifies it.
